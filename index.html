All about my Coding Journey

Welcome to my blog! This is where I share my progress as I learn how to code and make websites.

How it started

I started my coding journey when I joined the Coding Club at my school. The club gave me a chance to learn new skills, try different coding activities, and discover how much I enjoy creating things with technology.

Learning with Grok Academy

After joining the Coding Club, I joined Grok Academy and completed the HTML and CSS program. I learned how to structure webpages with HTML and style them with CSS. Building pages from scratch helped me understand how websites work and made me even more interested in web development.

My next step

My next step is to keep practising by making more websites. I want to experiment with different designs, improve my coding skills, and build projects that are useful and fun. Every website I make is another opportunity to learn something new.

Thanks for reading about my coding journey!
